# Design QA — Codex「产出项」v1.0.0

公开仓库保留可复现的测量结论，不收录维护者本机截图、绝对路径或真实任务标识。原始视觉证据在发布前由维护者离线核验，Release 构建与解包复验不依赖这些文件。

## v1.0.0 验证结论

- 深色模式画布为 `#181818`、正文为 `rgb(231,229,232)`；浅色模式画布为 `#f7f7f8`、正文为 `rgb(36,35,38)`。
- 两种主题下 `.workspace-grid` 均测得 `x=266, y=188, width=986, height=507`；主题切换只改变语义色彩 token，不移动布局。
- 根目录与每个嵌套层级都稳定地先显示文件夹、再显示普通文件；同类条目的原有顺序不变。
- 文件夹初始收起，单击只展开直接子项；嵌套层级保留独立展开状态和原始 `relativePath` 操作目标。
- 页面身份保持为“产出项”，两种主题均无框架错误覆盖层，浏览器控制台没有 warning 或 error。
- 任务标题轻量同步、Explorer 精确前置和 GitHub-ready Release 由服务端与发布包隔离测试覆盖。

## 回归结论

- 混合任务组始终把正常产出放在已删除产出之前；优先级和更新时间只在同一删除状态桶内排序。
- 全部产出均删除的任务组不显示；搜索已隐藏任务返回空结果，搜索混合任务内的已删除项仍保留该任务组。
- 可靠总大小显示在文件数量和版本之间；删除项不保留或显示历史大小。
- 概览操作顺序固定为检测状态、上传个人 GitHub、打开位置、删除产出项；四个按钮保持同宽同高。
- 破坏性确认明确列出目标与回收站效果，确认勾选前提交按钮不可用。
- 图片使用已登记文件的真实字节并受 magic、大小和像素限制；HTML、SVG 和脚本只按惰性纯文本显示。
- 伴生层切离产出项后完整恢复宿主标记与窗口控件，隔离 iframe 不增加 `allow-same-origin`。

## 结论

应用自有界面没有遗留可操作的 P0、P1 或 P2 视觉差异。安装后仍应在受支持的 Codex 版本上执行一次人工伴生窗口回归，以确认宿主 header selector 未变化。
